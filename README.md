# DataWallet_Project

Проект для анализа банковских транзакций с интеграцией внешних API и генерацией отчетов.

## 🚀 Основные возможности

### 1. **Главная страница**
- **Приветствие** в зависимости от времени суток
- **Анализ расходов** по картам: 
  - Последние 4 цифры карты
  - Общая сумма расходов
  - Кэшбэк (1 рубль на каждые 100 рублей в RUB)
- **Топ-5 транзакций** по сумме платежа
- **Курсы валют** (USD, EUR) через API ЦБ РФ
- **Цены акций** S&P500 через Twelve Data API

### 2. **Поиск транзакций**
- Поиск по описанию и категории
- Поддержка частичного совпадения
- Регистронезависимый поиск

### 3. **Отчетность**
- Анализ расходов по категориям за 3 месяца
- Автоматическое сохранение отчетов в папку `reports/`
- Поддержка пользовательских дат

## ⚙️ Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Temnodush/DataWallet_Project.git
   cd transaction-analytics
   ```

2. Установите зависимости через Poetry:
   ```bash
   poetry install
   ```

3. Настройте окружение:
   ```bash
   cp .env.example .env
   # Заполните API_KEY для Twelve Data
   ```

## 🛠 Использование

Запуск основного модуля:
```bash
poetry run python -m src.main
```

Примеры данных:
```python
# Пример транзакции в Excel:

----------------------------------------------------------
31.12.2021   | *7197       | Супермаркеты | -160.89 RUB
```

## 🧪 Тестирование

### Покрытие тестами
- **87% основного функционала**
- **Модульные тесты** для всех ключевых компонентов
- **Интеграционные тесты** для API

Основные тест-кейсы:
```python
# Пример теста для главной страницы
def test_main_views_success():
    with patch("src.views.get_currency_rates") as mock_rates:
        mock_rates.return_value = [{"USD": 75.5}]
        result = main_views("2023-01-01 00:00:00")
        assert "USD" in result["currency_rates"]
```

Запуск тестов:
```bash
poetry run pytest tests/ --cov=src --cov-report=term-missing
```

Особенности тестирования:
- **Mock объектов** для внешних API
- **Фикстуры** для генерации тестовых данных
- **Параметризация** тестовых случаев
- **Проверка обработки ошибок**
